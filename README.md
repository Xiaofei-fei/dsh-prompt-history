## 你能得到什么

`dsh-prompt-history` 把终端的输入历史搬进 DeepSeek Harness Web 输入框：

1. **类 shell 的方向键召回** — 空输入时 **↑** 召回上一条发送过的消息（最新在前）；**输入前缀后按 ↑** 跳到最近一条以该前缀开头的消息（bash 的 `history-search-backward` 行为），继续按 ↑ 往前翻匹配；**↓** 向后翻（含前缀匹配的前向），翻到底时**恢复你翻历史之前正在输入的那一行**（readline 的 pending-line 行为）。
2. **编辑即退出** — 浏览历史时一旦动手编辑，自动回到当前行，不再继续翻。
3. **Ctrl+R 反向搜索** — 增量搜索历史，输入时实时匹配最近条目（浮层显示 `(reverse-i-search)`查询`），再按 Ctrl+R 看更早匹配；Enter 采用、Esc 取消并恢复原输入。
4. **复制 + 引用（两种模式，设置里切换）** — 页面里任何非空选区——输入框、聊天消息、代码块等——按所选模式处理：
   - **工具栏**（默认）：选区上方出现「复制」「引用」按钮，侧聊开启时再多一个「侧聊追问」——复制点击才写剪贴板（不刷屏 Win+V）；**引用**把选中文本记成一条**注释**（Codex 风格，输入框**保持原样**）：输入框上方出现一条编号卡片（`1.` + 所选文本 + 编辑 / 删除），旁边是「N 条注 ×」胶囊，段落旁还会浮一个绿色编号角标指回原文；卡片平时收起，鼠标移到胶囊上才展开；发送时注释以 `>` 引用块拼到消息开头，发出后卡片与角标一起清空，聊天记录里则显示成「💬 N 条注释」胶囊（点开看原文）；**侧聊追问**把这段引用直接送进侧聊（见第 10 条），并在需要时自动开启侧聊面板。
   - **选中即自动复制**：终端风格，选中直接写系统剪贴板。
5. **鼠标右键直接粘贴** — 在输入框上右键即粘贴剪贴板内容（和 Linux 终端一致，不弹菜单）；粘贴走与 Ctrl+V 完全一致的管线（图片与引用 chip 行为一致），execCommand 路径被限制时自动回退到 Clipboard API 手动插入。
6. **跨会话历史记忆**（设置里可开关，默认关）— 开启后 ↑/↓ 历史在会话间保持，存于浏览器本地（上限 200 条），刷新/切换会话不丢失。
7. **提示词补全（Codex 风格，设置里可开关，默认开）** — 打字时若当前输入是历史里某条提示词的前缀，就在光标后**淡色显示剩余部分**，按 **Tab 或 →** 一次补全（Esc 忽略）；大小写不敏感匹配，`/`、`@` 开头的输入交给宿主自己的命令/引用菜单，不抢键。
8. **上下文预测建议（Codex 风格，设置里可开关，默认开）** — 输入框为空时，插件把最近几轮对话交给**当前会话模型**，预测你接下来可能发的那句话，并在输入框里**浅色整句显示** + 提示「按 Tab 键接受」；按 **Tab** 即填入（打字 / Esc / 新一轮即消失）。每轮回答结束后触发一次，输入框聚焦为空时补一次；请求期间输入框显示**浅色「正在预测下一条…」**（不再静默等待），结果到达即替换；**Ctrl+Shift+Space** 可随时手动预测一条（忽略过或等太久时用它）；同一段上下文命中缓存不重复请求。
9. **会话目录（Chat TOC）** — 聊天内容多时，对话左侧边缘有一个半透明、可拖动的把手（悬停变亮），点击展开按时间顺序列出你发送过的所有消息，点击任意一条即可跳转到对应位置；条目多时可在目录内滚动查看全部；点击外部或按 Esc 关闭。可在设置里**一键开关**。

10. **侧聊（设置里可开关，默认开）** — 在右侧栏开**第二条线程**，与主会话**并行干活**（共享同一工作区、可写文件）：
    - **带全部上下文本线程**：用宿主 `fork` 从当前会话分叉，继承整段对话；或**空白线程**从零开始（可开多条，chip 上有**未读徽标**与运行中标记）
    - 面板复用主输入框的全部手感：↑/↓ 历史、历史补全、上下文预测、Enter 发送、运行时「停止」
    - **窗口形态交给官方侧栏**：**⧉** 抽成浮动小窗、**◫** 右栏再开一栏、**⤓** 停靠回右栏、**✕** 关标签页
    - **双向桥接**：主会话选中 →「侧聊追问」送引用进面板；面板 **⇧** 把这条线程的结论以引用块写回主会话草稿
    - **并发写护栏**（默认开，只提醒不阻止）：从两侧工具行提取被触碰的文件路径，交集不为空时在面板列出「两侧都动过这些文件」
    - 面板收起时，侧栏标签上显示聚合未读数；侧聊的标签类型同时注册进侧栏自己的"添加标签页"引导页

纯 UI 行为：不产生会话事件、不改变 agent 循环。历史召回/引用/复制完全在浏览器内完成，**不发起任何请求**；唯一会调用模型的是「上下文预测建议」——它由你在设置里控制（默认开），开启时每轮最多向**当前会话模型**发一次极小的预测请求（约 512 tokens 预算），关闭后插件回到零网络。召回的文本只进入输入框草稿，引用则存放在插件自己的注释队列里（不进输入框），由你的发送动作在提交前并入消息；任何内容都只有**你**按 Enter 才会作为你的消息发出。

## 快速开始

```sh
# 1. 把插件装进你的 profile
dsh plugin --profile web add dsh-prompt-history

# 2. 刷新页面即可使用（无需重启服务）
```

## 安装与卸载

- **npm 渠道**（已发布版本）：`dsh plugin --profile web add dsh-prompt-history`
- **源码渠道**（本地开发，最新 `main`）：`dsh plugin --profile web add "github:Xiaofei-fei/dsh-prompt-history#main"`（源码检出需先 `pnpm run build` —— 未构建的 bundle 会拒绝启动）
- **卸载**：`dsh plugin --profile web remove dsh-prompt-history`

## 配置

打开 **设置 → `>_ 终端式输入`**（存于浏览器本地，修改立即生效）：

| 选项 | 默认 | 说明 |
|---|---|---|
| 复制方式（选中文字时） | `工具栏复制` | `工具栏`（推荐，点击才写剪贴板）/ `选中即自动复制`（终端风格） |
| 跨会话历史记忆 | 关 | ↑/↓ 历史在会话间保持，存于浏览器本地，上限 200 条 |
| 上下文预测建议（Tab 接受） | 开 | 输入框为空时用当前会话模型预测下一句；浅色整句显示，Tab 或 → 接受；请求期间显示「正在预测下一条…」；**Ctrl+Shift+Space** 手动预测一条（每轮一次，消耗少量额度） |
| 提示词补全（Tab 接受） | 开 | 打字时淡色补全历史中匹配的提示词，Tab 或 → 接受，Esc 忽略 |
| 会话目录（Chat TOC） | 开 | 对话左侧显示可拖动的目录把手，可关闭 |
| 右键直接粘贴 | 开 | 关闭后右键恢复浏览器原生菜单 |
| 侧聊 | 开 | 右侧栏出现「侧聊」标签页：与主会话并行的第二条线程（共享工作区、可写文件）。**关闭后，选区工具条里的「侧聊追问」按钮也随之消失**（1.4.1 起） |
| 并行写冲突提醒 | 开 | 侧聊与主会话碰到同一文件时在面板提醒（仅提醒，不阻止写入；关闭侧聊时该项隐藏） |

**键位速查**：↑/↓ 历史（含前缀搜索）· **Ctrl+R** 反向搜索 · **Tab / →** 接受补全或预测 · **Esc** 忽略预测 · **Ctrl+Shift+Space** 立即预测一条 · **Enter** 发送（侧聊面板内同）

↑/↓ 历史始终开启，不随以上开关变化。补全与 ↑ 用的是同一份历史与同一套前缀匹配语义。

## 特性

- **历史来自会话自身的消息记录**：直接读取会话快照中的用户消息节点（`user` / `steering`），随消息落地实时追加——与聊天记录严格一致，随会话持久化，刷新页面后依然可用，不需要任何配置或额外存储。
- **连续重复自动合并**，浏览状态跟随会话切换自动重置。
- **界面国际化**：全部文案（设置、工具栏、提示 pill、会话目录、搜索浮层）跟随 DSH 应用语言（中文 / English）。
- client bundle 压缩后约 12 KB；依赖全部走官方 `@deepseek-ai/*` peer 依赖。

## 已知限制

- **Ctrl+R**：输入框聚焦时 Ctrl+R 被用作反向搜索，**不再触发浏览器刷新**（想刷新先点一下输入框外面）。
- 会话目录会自动向后加载更早的宿主历史（逐页拉取直至完整），因此可定位全部历史位置；↑/↓ 召回仍只针对当前已加载窗口内的消息。
- 纯文本召回：带图片/命令 chip 的消息不参与；召回内容为纯文本。

## 原理

插件是一个不可见的 composer 槽位条目：挂一个 document 捕获期 keydown 监听，仅在目标为 composer 输入框、无修饰键、非输入法组合、菜单未打开、会话非忙碌时接管 ↑/↓，通过 `inputActions.setDraft` 写入历史文本。历史列表由会话快照的 `user`/`steering` 节点按 seq 去重追加，浏览位置（index + 待恢复的当前行）保存在组件 ref 中。
