## 你能得到什么

`dsh-prompt-history` 把终端的输入历史搬进 DeepSeek Harness Web 输入框：

1. **类 shell 的方向键召回** — 空输入时 **↑** 召回上一条发送过的消息（最新在前）；**输入前缀后按 ↑** 跳到最近一条以该前缀开头的消息（bash 的 `history-search-backward` 行为），继续按 ↑ 往前翻匹配；**↓** 向后翻（含前缀匹配的前向），翻到底时**恢复你翻历史之前正在输入的那一行**（readline 的 pending-line 行为）。
2. **编辑即退出** — 浏览历史时一旦动手编辑，自动回到当前行，不再继续翻。
3. **Ctrl+R 反向搜索** — 增量搜索历史，输入时实时匹配最近条目（浮层显示 `(reverse-i-search)`查询`），再按 Ctrl+R 看更早匹配；Enter 采用、Esc 取消并恢复原输入。
4. **复制 + 引用（两种模式，设置里切换）** — 页面里任何非空选区——输入框、聊天消息、代码块等——按所选模式处理：
   - **工具栏**（默认）：选区上方出现「复制」「引用」按钮，侧聊开启时再多一个「侧聊追问」——复制点击才写剪贴板（不刷屏 Win+V）；**侧聊追问**把这段引用直接送进侧聊（见第 10 条），并在需要时自动开启侧聊面板。
   - **引用（笔记式）**：选中消息后点「引用」先弹一个**评论框**（原文在上、可写一句评论、可勾「让模型逐条回应」）；
     确认后**草稿保持为空**，引用作为**编号笔记卡片**停在输入框上方（`N 条注` 胶囊），卡片可展开、可改、可删；
     你照常写提示词，按 **Enter** 或点发送时由插件把笔记**并入这一条消息**（复用 `> ❝/❞` 块格式），
     发送后消息里显示「N 条注」胶囊而不是一屏引用行；**代码引用仍是带语言与围栏的代码块**，插入后来源消息
     仍会滚到视野并闪一下（纯视觉提示，不写进文本）。写入或发送失败时笔记**保留**、可重试，不会被静默吞掉；
     宿主没有 `submit` 动作面时插件不接管发送，普通发送不受影响。
     避免两条工具栏叠在一起（可在设置里关闭该让位）。
   - **选中即自动复制**：终端风格，选中直接写系统剪贴板。
5. **鼠标右键直接粘贴** — 在输入框上右键即粘贴剪贴板内容（和 Linux 终端一致，不弹菜单）；粘贴走与 Ctrl+V 完全一致的管线（图片与引用 chip 行为一致），execCommand 路径被限制时自动回退到 Clipboard API 手动插入。
6. **跨会话历史记忆**（设置里可开关，默认关）— 开启后 ↑/↓ 历史在会话间保持，存于浏览器本地（上限 200 条），刷新/切换会话不丢失。
7. **提示词补全（Codex 风格，设置里可开关，默认开）** — 两个来源、一个浮层、严格优先级：
   - **先查历史**：当前输入是历史里某条提示词的前缀时，在光标后**淡色显示剩余部分**（免费、即时）。
   - **再问模型**（独立开关，默认开）：历史没有匹配时，停顿约 450ms 后把「你已打的半句 + 最近对话」交给**当前会话模型**，把这句话缺的后半截淡色补在光标后——所以你打「把第 3 点」时它能顺着往下补，而不是必须一字不差重敲旧提示词才有反应。
   两种都按 **Tab 或 →** 一次接受（Esc 忽略）；大小写不敏感，`/`、`@` 开头交给宿主自己的菜单，不抢键；同一个半句最多问一次（含「没什么可补」的结果，按草稿缓存）。
8. **上下文预测建议（Codex 风格，设置里可开关，默认开）** — 输入框为空时，插件把最近几轮对话交给**当前会话模型**，预测你接下来可能发的那句话，并在输入框里**浅色整句显示** + 提示「按 Tab 键接受」；按 **Tab** 即填入（打字 / Esc / 新一轮即消失）。每轮回答结束后触发一次，输入框聚焦为空时补一次；请求期间输入框显示**浅色「正在预测下一条…」**（不再静默等待），结果到达即替换；**Ctrl+Shift+Space** 可随时手动预测一条（忽略过或等太久时用它）；同一段上下文命中缓存不重复请求。它读取最近 12 轮对话：工具调用与计划行会被跳过，长回复**头尾都保留**（结论通常在最末尾，正是决定下一句该问什么的部分），只随重绘变化的时间戳会被剔除。

9. **提示词增强（设置里可开关，默认开）** — 输入框动作行的 **✨** 按钮把当前草稿改写为**结构化提示词**（角色与目标、上下文与约束、可执行步骤、输出格式、验收标准、边界情况），用的是**当前会话模型**：
   - **绝不自动替换也不自动发送**：改写结果进「原文 / 增强后」对比面板，只有点**应用**才写回草稿；写回后在输入框上方出现**撤销**条，一键还原，继续打字则撤销条自动退休
   - **绝不编造**：草稿里没给的信息会写成「（待补充：…）」占位，而不是替你想；保持原语言、长度控制在 1–3 倍
   - 空草稿 / 超长（>12000 字）/ 正在发送时按钮自动置灰；失败只提示、不改草稿，可就地重试；`Esc` 关闭面板
   - 面板支持**复制**、**取消**、**重试**；全部文案随 DSH 语言（中/英）

10. **侧聊（设置里可开关，默认开）** — 在右侧栏开**第二条线程**，与主会话**并行干活**（共享同一工作区、可写文件）：
    - **带全部上下文本线程**：用宿主 `fork` 从当前会话分叉，继承整段对话；或**空白线程**从零开始（可开多条，chip 上有**未读徽标**与运行中标记）
    - 面板复用主输入框的全部手感：↑/↓ 历史、历史补全、上下文预测、Enter 发送、运行时「停止」
    - **窗口形态交给官方侧栏**：**⧉** 抽成浮动小窗、**◫** 右栏再开一栏、**⤓** 停靠回右栏、**✕** 关标签页
    - **双向桥接**：主会话选中 →「侧聊追问」送引用进面板；面板 **⇧** 把这条线程的结论以引用块写回主会话草稿
    - **并发写护栏**（默认开，只提醒不阻止）：从两侧工具行提取被触碰的文件路径，交集不为空时在面板列出「两侧都动过这些文件」
    - 面板收起时，侧栏标签上显示聚合未读数；侧聊的标签类型同时注册进侧栏自己的"添加标签页"引导页

11. **提示词模板（📋，设置里可开关，默认开）** — 输入框动作行的 **📋** 打开常用提示词面板：**装好就有 5 条起步模板**（代码审查 / 解释代码 / 写测试 / 找边界情况 / 重构建议），点一行就把正文**按光标位置**写进草稿——不发送，也不覆盖你已经写的内容。
    - **从草稿攒模板**：把想复用的提示词打在输入框里，点「存为模板」即收成面板里的一行；行上 **✎** 改名改正文、**✕** 删除（带二次确认）。
    - **面板自带筛选**，↑/↓ 选、**Enter** 插入、**Esc** 关闭；点击行时不会抢输入框焦点，所以光标停在哪就在哪插入。面板带 `role="dialog"`，插件的补全/预测灰字会自动让到面板下面，不会糊在列表上。
    - 模板存于**浏览器本地**（上限 100 条、正文上限 8000 字），纯本地、不发请求；正在发送的轮次里按钮自动置灰。

纯 UI 行为：不产生会话事件、不改变 agent 循环。历史召回/引用/复制完全在浏览器内完成，**不发起任何请求**；会调用模型的是「上下文预测建议」与「AI 续写」——都由你在设置里控制（默认开），开启时每轮、每次打字停顿最多向**当前会话模型**发一次极小的请求（约 512 tokens 预算），关闭后插件回到零网络。召回/引用/预测的文本都只进入输入框草稿，只有**你**按 Enter 才会作为你的消息发出。


## 安装与卸载

- **npm 渠道**（已发布版本）：`dsh plugin --profile web add dsh-prompt-history`

## 配置

打开 **设置 → `>_ 终端式输入`**（存于浏览器本地，修改立即生效）：

| 选项 | 默认 | 说明 |
|---|---|---|
| 复制方式（选中文字时） | `工具栏复制` | `工具栏`（推荐，点击才写剪贴板）/ `选中即自动复制`（终端风格） |
| 跨会话历史记忆 | 关 | ↑/↓ 历史在会话间保持，存于浏览器本地，上限 200 条 |
| 上下文预测建议（Tab 接受） | 开 | 输入框为空时用当前会话模型预测下一句；浅色整句显示，Tab 或 → 接受；请求期间显示「正在预测下一条…」；**Ctrl+Shift+Space** 手动预测一条（每轮一次，消耗少量额度） |
| 提示词补全（Tab 接受） | 开 | 打字时淡色补全历史中匹配的提示词，Tab 或 → 接受，Esc 忽略 |
| 提示词增强（✨） | 开 | 输入框动作行的 ✨ 把草稿改写为结构化提示词；对比后手动应用，可撤销（每次一次小请求） |
| AI 续写（Tab 接受） | 开 | 历史没有匹配时，停顿后让模型补完你已打的半句；Tab 或 → 接受（每次停顿一次小请求） |
| 右键直接粘贴 | 开 | 关闭后右键恢复浏览器原生菜单 |
| 提示词模板（📋） | 开 | 输入框动作行的 📋 打开常用提示词面板，点一行按光标位置写入草稿；模板存于浏览器本地（上限 100 条），不发请求 |
| 侧聊 | 开 | 右侧栏出现「侧聊」标签页：与主会话并行的第二条线程（共享工作区、可写文件）。**关闭后，选区工具条里的「侧聊追问」按钮也随之消失**（1.4.1 起） |
| 并行写冲突提醒 | 开 | 侧聊与主会话碰到同一文件时在面板提醒（仅提醒，不阻止写入；关闭侧聊时该项隐藏） |

**键位速查**：↑/↓ 历史（含前缀搜索）· **Ctrl+R** 反向搜索 · **Tab / →** 接受补全或预测 · **Esc** 忽略预测 · **Ctrl+Shift+Space** 立即预测一条 · **Enter** 发送（侧聊面板内同）

↑/↓ 历史始终开启，不随以上开关变化。补全与 ↑ 用的是同一份历史与同一套前缀匹配语义；历史那一路始终免费，只有模型兜底会消耗额度。

## 特性

- **历史来自会话自身的消息记录**：直接读取会话快照中的用户消息节点（`user` / `steering`），随消息落地实时追加——与聊天记录严格一致，随会话持久化，刷新页面后依然可用，不需要任何配置或额外存储。
- **连续重复自动合并**，浏览状态跟随会话切换自动重置。
- **界面国际化**：全部文案（设置、工具栏、提示 pill、搜索浮层）跟随 DSH 应用语言（中文 / English）。
- client bundle 压缩后约 12 KB；依赖全部走官方 `@deepseek-ai/*` peer 依赖。

## 已知限制

- **Ctrl+R**：输入框聚焦时 Ctrl+R 被用作反向搜索，**不再触发浏览器刷新**（想刷新先点一下输入框外面）。
- 纯文本召回：带图片/命令 chip 的消息不参与；召回内容为纯文本。

## 原理

插件是一个不可见的 composer 槽位条目：挂一个 document 捕获期 keydown 监听，仅在目标为 composer 输入框、无修饰键、非输入法组合、菜单未打开、会话非忙碌时接管 ↑/↓，通过 `inputActions.setDraft` 写入历史文本。历史列表由会话快照的 `user`/`steering` 节点按 seq 去重追加，浏览位置（index + 待恢复的当前行）保存在组件 ref 中。
